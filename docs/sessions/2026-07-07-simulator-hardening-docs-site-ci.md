### 2. SURE simulator review hardening (PR #3)

Resolved all 18 CodeRabbit findings on the simulator with fixes across
`include/dfa/sim/`:

- **Fail-fast guards:** `HalfSpace::satisfied` rank mismatch, `Domain::axis`
  bounds check, `Domain::add` dimension validation, ragged-matrix rejection
  in `AffineDependency`, duplicate-name rejection in `RecurrenceSystem::add`
- **Schedule correctness:** `LinearSchedule`/`PiecewiseLinearSchedule::time`
  throw on tau/index-point rank mismatch instead of silently truncating
  (which could mask illegal schedules in `checkLegality`)
- **Simulator:** dependency-cycle detection in `eval()` and
  `computeFreeSchedule()` (diagnostic instead of stack overflow); drained
  (never-consumed) outputs no longer counted as resident in `analyzeMemory()`
  or `run()`, matching the documented drain-at-birth semantics
- **Importer:** unary lowering gained the shape validation the binary path
  had; both now check per-axis broadcast compatibility; multi-output
  producers fail fast; `unresolvedTaps` diagnostic in `LegalityReport`
- **CLI:** `--quiet` now works with `--dfg`; `listSpecs` handles exceptions
- **Tests:** `matmul3_sim`/`matvec_sim` reuse the canonical spec builders

All 67 ctest tests green with zero warnings before merge.

### 4. Astro/Starlight documentation site (PR #8)

`docs-site/` modeled on the mtl5 and embodied-ai-architect sites, published
automatically to GitHub Pages at https://branes-ai.github.io/domain_flow/.
Key architectural rule: `src/content/docs/` is 100% generated by
`sync-content.mjs` from the repo `docs/` tree, so repo markdown remains the
single source of truth. KaTeX math, landing page with capability cards
(`docs/site/index.mdx`), sidebar sections for Getting Started / Architecture /

`%BASE%` placeholder), per-page `editUrl` pointing at real sources (the
global editLink would have 404'd), and hard build failure on missing mapped
sources. Pages was enabled with `build_type: workflow` via the API.

### 5. CI overhaul (issues #7, #10; PR #9)

Root causes identified for docs-only PRs spending ~4h in CI: no path
filtering; LLVM caches are branch-scoped so PR-branch caches are invisible
to siblings; main's cache evicted after 7 idle days; no `restore-keys`; and
the cache key hashed a nonexistent `llvm-build-config.txt` (empty hash).

Fixes in `.github/workflows/cmake-multi-platform.yml`:
- `paths-ignore` for `**.md`, `docs/**`, `docs-site/**`, `LICENSE`
- weekly scheduled cache-warmer run on main + `workflow_dispatch`
- `restore-keys` prefix fallback (shaped to adopt pre-existing caches)
- `llvm-build-config.txt` created as a real configure-flag fingerprint
- clone/build steps gated on an install-tree probe (`mlir-tblgen` + `clang`)
  because prefix restores report `cache-hit=false`
- concurrency group; auto-cancel restricted to `pull_request` events so an
  in-progress main cache build is never killed before its post-job save

**Validated:** matrix jobs on the fix PR restored the cache and skipped the
LLVM build steps entirely — green in 1m54s-4m34s. Issue #10 tracks the
remaining (rare) cold-cache duplicate build across ubuntu compiler legs.

### 6. Operational cleanup
